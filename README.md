# Шаблон для Next.js 

Базовый шаблон для быстрого старта проектов на Next.js.

### Стек

* Next.js
* TypeScript
* Tailwind CSS
* shadcn/ui
* Feature-Sliced Design
* Biome

Шаблон содержит базовую структуру проекта и готовую конфигурацию для дальнейшей разработки.

Используй **Use this template** на GitHub, чтобы создать новый проект на основе этого репозитория.

---

### Установка зависимостей
Если pnpm уже установлен:
```
pnpm install
```

Если pnpm ещё не установлен:
```
npm install -g pnpm
```

Проверка:
```
pnpm -v
```
